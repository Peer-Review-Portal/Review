# Footy Hub

index.html   - the site
games.json   - list of extra games: [{"name":"My Game","path":"games/my-game/index.html","icon":"🎮","desc":"..."}]
games/       - one folder per game (only games you have the rights to use)
logos/       - team logo PNGs named by code (HAW.png etc.)
